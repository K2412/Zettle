# Zettle (Inertia) — Note Synthesis

A single-user, local-first Zettelkasten note app. React + Inertia v3 front end over a Laravel
back end. This context covers the note graph: notes, the links between them, and their tags.

## Language

**Note**:
The durable unit of the app — a title, a markdown body, a type, and a URL slug. Notes link to
one another and carry tags.

**Fleeting note**:
A raw capture from your own thinking. A starting point, not a keeper. The default type a new note
is created as unless another is chosen.
_Avoid_: quick note, scratch note

**Literature note**:
A capture of what a source says, in your own words, tied to a source location.
_Avoid_: reading note, highlight

**Permanent note**:
A self-contained note making one intellectual move, in your own words, connected into the graph.
_Avoid_: evergreen note, atomic note

**Structure note**:
An interpreted map of a cluster of permanent notes — their argument, branches, open questions.
_Avoid_: MOC, map note

**Project note**:
An instrumental, disposable document that pulls permanent notes into an ordered sequence for one
deliverable. Discarded after use; never consumes the notes it draws from.
_Avoid_: draft, outline

**Connection**:
A directed, typed link from one note to another (with an optional rationale). The edges of the graph.
_Avoid_: link (ambiguous), edge

**Typed connection**:
A connection the user authored by hand, whose relationship is one of the synthesis vocabulary
(supports, contradicts, depends_on, …) — an asserted claim about how two notes relate, distinct from
a `mentions` edge that a wikilink creates automatically.
_Avoid_: manual link, relation

**Wikilink**:
The `[[Note Title]]` syntax typed in a note body. On save the server reconciles wikilinks into
`mentions` connections. The plain-text authoring surface for the graph.
_Avoid_: internal link, backlink (that is the reverse direction)

**Mention**:
The connection type a wikilink produces. Distinct from connections a user authors explicitly, which
survive re-parsing of the body.

**Backlink**:
The reverse direction of a connection — the notes that link *to* the note you are viewing.
_Avoid_: inbound link

**Inverse label**:
The display-only phrasing the target note shows for an inbound typed connection (`supports` →
"supported by"). Symmetric relationships (contradicts, analogous_to, tension_with, distinguishes_from)
read the same both ways. The edge is stored once; the inverse is computed, never a second row.

**Tag**:
A user-owned, colored label attached to notes; used to filter the note list. Managed on a dedicated
tags surface where it can be renamed, recolored (a free hex color), deleted, or merged. Its `slug`
(derived from the name) is the dedup key — one name resolves to one tag — so renaming re-slugs it.

**Tag merge**:
Folding one tag (the source) into another (the target): every note carrying the source gains the
target instead, then the source is deleted. The target's name and color survive. The explicit path for
combining two tags that mean the same thing — distinct from a rename, which never destroys a tag.

**Embedding**:
A vector of a note's title+body, generated by the AI SDK and stored in sqlite-vec, capturing the
note's meaning for similarity search.

**Semantic search**:
Finding notes by meaning (embedding similarity) rather than exact words. The note search box is
**hybrid** — it blends keyword matches with semantic ones on an explicit search.
_Avoid_: vector search (the mechanism, not the feature)

**Discovery**:
Surfacing notes related to the one you're viewing by embedding nearness (nearest-neighbour), as
ranked suggestions to connect. Distinct from a wikilink mention and from an authored connection — a
suggestion, never a stored edge until you assert one.
_Avoid_: recommendation, related notes

**Assist**:
An on-demand AI action the agent runs on a note to help move it forward — always read-only to the
note's own title and body. An assist proposes; the user disposes. Each assist belongs to one phase.
_Avoid_: AI feature, automation, agent (the agent runs assists; it is not one)

**Phase**:
One step in the note-synthesis playbook (triage, atomize, formulate, connect, make findable,
structure, cluster to project). Each phase names the move a note needs next; the panel suggests one
but never forces it.
_Avoid_: stage, step, mode

**Atomize**:
The assist that reads a note holding several ideas and proposes each as its own candidate note title.
Accepting one spawns a fresh permanent note linked back to the origin — the origin note is never
rewritten.
_Avoid_: split, extract, break up

**Triage**:
The assist that reads a note and suggests where it should go and what type it should be. Running it
only proposes; the one thing the user can then write is the note's type — never its title or body.
_Avoid_: sort, categorize, classify (that is the mechanism, not the assist)

**Triage destination**:
Where a triaged note should head next (`discard`, `task`, `project_only`, `keep_literature`,
`develop`, `question`, `multi_idea`) — a routing hint the user reads, not a field stored on the note.
_Avoid_: category, bucket, status

**Formulate**:
The read-only assist for shaping a single note. It offers scaffold templates to start from and
critiques a draft as prose — and writes nothing at all, not even the note's type.
_Avoid_: draft, compose, generate

**Scaffold template**:
An empty, type-appropriate markdown skeleton (permanent, argument, distinction, mechanism, question,
tension, application, counterexample) the user copies into a note and fills in themselves. Static
client-side text — no AI, no round-trip.
_Avoid_: boilerplate, snippet, form

**Draft critique**:
The prose feedback Formulate returns on a draft the user has written — read-only guidance surfaced in
the panel, never pasted into or persisted on the note.
_Avoid_: correction, edit, suggestion (it advises; it does not change the note)

**Provenance connection**:
The typed connection a spawned note carries back to the note it came from (`provenance`), recording
where the idea originated. Created automatically on spawn; it reads as a backlink on the origin.
_Avoid_: parent link, source link, origin link

**Assist panel**:
The sidebar surface that holds the phase tabs and the active assist. Which phase is active is
ephemeral client state — switching a tab swaps the shown assist, never touching or navigating the
note.
_Avoid_: AI sidebar, assistant panel, tools panel

**Phase suggestion**:
The one phase the panel marks and opens first, derived deterministically from the note's current
state (its type, whether it has a body, whether it is connected). A hint, not a verdict — the user is
always free to pick another phase.
_Avoid_: recommended phase, default phase
